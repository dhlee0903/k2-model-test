# K2 소총 시뮬레이터

브라우저에서 돌아가는 K2 소총 3D 시뮬레이터. 파일 하나(`index.html`)에 three.js(r128, CDN)로 모델·작동·사운드를 전부 담았다.

- 배포: https://k2-simulator.vercel.app
- 실행: `index.html`을 브라우저로 열면 끝(인터넷 연결 필요 — three.js를 CDN에서 받음)

## 조작

| 키 | 동작 |
|---|---|
| 클릭 / Space | 방아쇠 (누르고 있으면 연발) |
| Q | 조정간 (안전 → 단발 → 연발 → 점사, 한 방향으로 계속 돌아감) |
| F | 노리쇠 당기기 (장전손잡이 드래그도 가능, 후퇴고정 중이면 당겼다 놓아 전진) |
| C | 노리쇠멈치: 후퇴고정 / 눌러서 전진 (총의 멈치를 클릭해도 됨) |
| R | 탄창 분리 / 결합 |
| N | 새 탄창(30발) |
| G | 가스조절기 (0 차단 / 소 더운 날씨 / 중 정상 / 대 악조건) |
| B | 대검 결합 / 분리 |
| V | 개머리판 접기 / 펴기 |
| X | 투명 보기 (내부 부품·노리쇠 왕복·급탄이 보임) |
| D | 분해: 1번 = 윗몸통 열고 노리쇠뭉치 통째로 꺼냄, 2번 = 노리쇠뭉치 분해, 3번 = 조립 |
| Tab | 점검 ↔ 사격장 |

## 로컬에서 미리보기

```bash
python -m http.server 8765
```

`http://localhost:8765/` 접속.

## 배포

```bash
npx vercel deploy --prod
```

(Vercel 프로젝트 `k2-simulator`. `.vercel/`은 커밋하지 않으니, 다른 PC에서 처음 배포할 땐 `npx vercel link`로 같은 프로젝트에 연결.)

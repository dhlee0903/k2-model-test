# K2 소총 자료 조사 (출처 포함)

가장 신뢰도 높은 1차 자료: **Daewoo DR200 사용설명서**(K2 민수용 반자동판, 부품 목록 포함)
https://archive.org/details/gunmanual_Daewoo_Dr200 (텍스트: https://archive.org/download/gunmanual_Daewoo_Dr200/Daewoo%20Dr200_djvu.txt)
한국군 기술교범(TM)은 확보하지 못함. 나무위키 내용은 요약을 거친 2차 정보.

## 1. 작동 방식
- **장행정 가스피스톤 + 회전노리쇠** (AK 계열, K1의 가스직동식과 다름) — https://en.wikipedia.org/wiki/Daewoo_Precision_Industries_K2 , https://ko.wikipedia.org/wiki/K2_%EC%86%8C%EC%B4%9D
- 가스실린더는 총열 위, 가스조절기는 그 앞쪽. 피스톤은 별도의 작동간(operating rod)에 핀으로 연결(DR200 부품: Piston, Pin(Piston), Operating Rod).
- 초기형은 피스톤 연장부가 노리쇠뭉치에 핀 고정, 후기형은 분리 — https://www.falfiles.com/threads/daewoo-rifle-information-faq.450267/
- 노리쇠: AR형, **돌기 7개**(하나는 고정 탄피배출기 자리로 깎임) — https://thenewrifleman.com/classic-rifle-review-the-daewoo-k2-koreas-answer-to-the-ar15/ . M16과 비슷하지만 호환 안 됨.

## 2. 복좌용수철
- **윗총몸 안, 노리쇠뭉치 위쪽에 가는 용수철 1개**(AK식). 완충기 튜브 없음 — https://modernfirearms.net/en/assault-rifles/south-korea-assault-rifles/daewoo-k1-i-k2-eng/
- AR-18의 두 줄 용수철과 다름(나무위키 대비 설명) — https://en.namu.wiki/w/K2%20%EC%86%8C%EC%B4%9D
- DR200 부품: Bushing(Recoil Spring), Helical Compression Spring, Rod(Large), Supporter Assembly → 막대(rod)에 끼운 용수철. 뒤쪽 supporter가 윗총몸 잠금 역할도 함("Push supporter … and pivot upper receiver").
- 미확인: 작동간과 같은 축인지, 옆 막대인지.

## 3. 노리쇠뭉치
- 부품(DR200): 노리쇠뭉치(carrier), 공이고정핀, 공이, 캠핀, 추출기 핀/추출기/추출기 용수철, 노리쇠.
- AR식: 공이가 노리쇠를 관통, 고정핀을 빼면 뭉치 뒤로 빠짐. 분해 순서: 고정핀 → 공이 → 캠핀 → 노리쇠. 고정핀은 공이의 큰 어깨 뒤에 걸림.
- **장전손잡이: 오른쪽, 노리쇠뭉치에 붙은 둥근 손잡이(분리 가능), 사격 시 함께 왕복.**

## 4. 방아쇠 뭉치
- 아랫총몸의 M16식 공이치기·방아쇠·단발자(disconnector), 3점사 기구 포함. 방아쇠를 일찍 놓으면 점사 카운트가 리셋되지 않는다는 2차 자료 있음(미검증).
- 공이치기 핀이 방아쇠 핀보다 뒤·위(AR 배치, 매우 유력하나 K2 도면으로 미확인).

## 5. 조정간
- 왼쪽, 손잡이 위. 순서: **안전 → 단발 → 연발 → 점사 (왼쪽부터 시계방향)**, 연발 있음(나무위키, ko.wikipedia).
- 360° 회전 가능: 안전→단발→연발 / 안전→점사→연발 양쪽으로 돌릴 수 있음 — https://namu.wiki/w/%EC%A1%B0%EC%A0%95%EA%B0%84
- 미확인: 각인 글자 형태와 정확한 각도.

## 6. 가스조절기
- K2: **4단 — 0(총류탄/차단), 소(더운 날씨), 중(정상/사계절), 대(추운/악조건)** (나무위키).
- DR200: 0 / L / M / S, 걸쇠를 누르고 돌림.

## 7. 분해
- 앞 분해핀 축으로 윗총몸이 열림(복좌용수철 supporter를 눌러 풂). 핀을 안 빼도 "ㄱ"자로 열어 청소 가능.
- DR200 순서: 복좌용수철 뭉치 → 장전손잡이 → 분해핀 빼서 위/아래 분리 → 총열덮개 → 노리쇠뭉치 분해.
- 한국어 명칭(2차 자료): 노리쇠뭉치, 장전손잡이, 복좌용수철(밀대)뭉치, 가스피스톤, 가스조절기, 윗총몸/아랫총몸, 총열덮개.

## 8. 개머리판
- **오른쪽으로 접힘**, 접은 채 사격 가능. 플라스틱(속이 빈지 미확인).

## 9. 탄창
- STANAG(M16) 20/30발 호환.
- 나무위키: 탄 수가 짝수면 우상탄 → **30발 = 우상탄** (단일 출처, 미검증).
